Prototype component guidance

Typeahead and multiselect components

These JavaScript enhancements make long GOV.UK radio and checkbox lists searchable while keeping the original form controls and submitted values.

These are prototype components, not official GOV.UK Design System components. Test them with users and assistive technologies before using them in a live service.

Changes 22/10/26

  • The selected-items summary is now optional and is hidden by default.
  • Focusing the search field no longer opens the drop down list by default.
  • The dropdown arrow and opening the list on focus are now separate options.
  • All of the options have been renamed to be clearer.
  • When a keyboard user selects a checkbox with the Space key, focus remains on that checkbox.

Add the components to your prototype

  1. Add the application JavaScript to your prototype js fileapp/assets/javascripts/application.js, or load it from a separate JavaScript file.
  2. Add the component styles to app/assets/sass/application.scss, or import them from a separate Sass file.
  3. Add js-multiselect to GOV.UK checkboxes or js-typeahead to GOV.UK radios.
  4. Add required options via data attributes.

Checkbox multiselect

Add the js-multiselect class to a GOV.UK checkboxes component. Without JavaScript, the original checkbox list remains available.

Default behaviour

The default version shows a labelled search field. The selected-items summary and dropdown arrow are hidden. Focusing the search field does not open the list. The filtered list opens when the user types.

{{ govukCheckboxes({ idPrefix: "multiselect", name: "demo[multiselect]", classes: "js-multiselect", fieldset: { legend: { text: "Select items", classes: "govuk-fieldset__legend--m" } }, hint: { text: "You can select more than one option." }, items: [ { text: "Item 1", value: "Item 1"}, { text: "Item 2", value: "Item 2" }, { text: "Item 3", value: "Item 3"}, { text: "Item 4", value: "Item 4"}, { text: "Item 5", value: "Item 5"}, { text: "Item 6", value: "Item 6" }, { text: "Item 7", value: "Item 7"}, { text: "Item 8", value: "Item 8" }, { text: "Item 9", value: "Item 9"} ] }) }}

Multiselect options

Options applied to the GOV.UK checkboxes component
Attribute Values Default What it does
data-options-search-labelTextSearchSets the visible label for the generated search field.
data-options-search-placeholderTextSearchSets optional placeholder text. Do not use it instead of a visible label.
data-options-show-selected-itemstrue or falsefalseShows a summary above the search field containing selected items and Remove buttons.
data-options-show-dropdown-arrowtrue or falsefalseAdds a button that opens and closes the options list.
data-options-show-dropdown-list-on-focustrue or falsefalseOpens the full options list when the search field receives focus.
data-multiselect-sectionstrue or falsefalseGroups results beneath headings taken from each item’s data-section attribute.
data-multiselect-searchtrue or falsetrueSet to false to replace the search field with a compact filter trigger.
data-multiselect-triggerTextAllSets the default trigger text when search is disabled.
data-sectionText on each checkbox itemNoneDefines the section heading for an item when sections are enabled.
data-multiselect-othertrue on one checkboxfalseKeeps an Other option and its conditional reveal outside the searchable results.

Using options

The options are independent. In this example, the component shows selected items, includes a dropdown arrow, opens when focused and groups results under headings.

Radio typeahead

Add the js-typeahead class to a GOV.UK radios component. With JavaScript enabled, the radios become a searchable single-select control. The original radio list remains available without JavaScript.

Implementation

{{ govukRadios({ idPrefix: "demo-operation", name: "demo[operation]", classes: "js-typeahead", attributes: { "data-typeahead-label": "Search items", "data-typeahead-placeholder": "Start typing an item name" }, fieldset: { legend: { text: "Select an item", classes: "govuk-fieldset__legend--m" } }, items: [ { text: "Item 1", value: "Item 1" }, { text: "Item 2", value: "Item 2" }, { text: "Item 3", value: "Item 3" }, { text: "Item 4", value: "Item 4" }, { text: "Item 5", value: "Item 5" } ] }) }}

Typeahead options

AttributePurposeDefault
data-typeahead-labelSets the visible label for the generated search input.Search
data-typeahead-placeholderSets optional placeholder text inside the search input.Search

Keyboard behaviour

  • Tab moves through the search field, optional dropdown button and each visible option.
  • Space selects or clears a focused checkbox.
  • After Space is pressed, focus remains on the checkbox that changed.
  • Escape closes an open options list.
  • Typing filters the available options and opens the results.

Accessibility and implementation notes

  • Keep the original GOV.UK radio or checkbox component in the page.
  • Give every generated search input a visible label.
  • Do not rely on placeholder text as the label.
  • Do not reuse IDs or names across unrelated components.
  • Test the unenhanced controls with JavaScript disabled.
  • Test keyboard operation, screen-reader output, zoom, reflow and validation errors.
  • Do not treat these components as production-ready without service-specific testing.

How submitted data works

The enhancement checks and clears the original GOV.UK controls. Existing routes continue to receive the original names and values, so they should not need changes solely because the enhancement is added.

demo: {
  multiselect: ["Item 1", "Item 3"]
}
